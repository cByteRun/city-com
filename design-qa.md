# Проверка интерфейса CityCom

Визуальная основа: предоставленные заказчиком локальные материалы, рассмотренные непосредственно в сессии. Названия и ссылки на них не публикуются.

Проверены общий экран, подразделения, проблемы с панелью деталей, источники, качество, администрирование, ассистент и мобильный обзор. Материал сравнения — изображение 1440 × 1488; реализация — скриншот при CSS viewport 1440 × 900, deviceScaleFactor 1, полная высота страницы зависит от содержимого. Промежуточная сверка выполнена при 1440 × 1000, затем viewport приведён к 1440 × 900. Изображения не растягивались.

Состояние: светлая тема, DEMO, период 30 дней, без дополнительных фильтров. Числа, даты, порядок кластеров и форма кривых намеренно вычисляются из собственного набора обращений. Они не копируются из изображения. Мобильная проверка: 390 × 844, scale 1.

- Композиция: sidebar 250 px, header 75 px, рабочие отступы 26 px, пять KPI, сетка панелей 1.4/1, общие фильтры в две строки. На mobile меню выдвигается, KPI образуют две колонки, панели располагаются вертикально. Таблицы прокручиваются внутри собственного контейнера.

## Исправления по итерациям

1. [P1, исправлено] Первый вход оставался в загрузке после отклонённого запроса. Исправлена проверка origin относительно Host и завершение loading при ошибке. Проверено реальным браузерным входом и четырьмя E2E-сценариями.
2. [P2, исправлено] Снимок мог захватывать пустые начальные кадры графиков. Отключена анимация серий, повторные снимки показывают кривые и donut.
3. [P2, исправлено] Фильтр приоритета попадал в первую строку, меняя ритм. Добавлен разрыв после шести основных фильтров; mobile использует собственную сетку.
4. [P2, исправлено] Заголовки панелей были визуально слишком лёгкими после CSS reset. Установлен вес 700 для h2 и 650 для h3.
5. [P2, исправлено] Уведомление об успехе за модальной панелью не объявлялось скринридеру. Добавлен inline status непосредственно в панель деталей; повторный сценарий подтверждает сохранение назначения и модерации.

Блокирующих визуальных замечаний не осталось. Допустимые различия: динамические данные, дополнительные обязательные рабочие разделы, иконки библиотеки, доступные выпадающие контролы, подсказка раннего выявления и элементы сохранения фильтров. Эти отличия не нарушают композицию или основную задачу.

## Проверки взаимодействий

Четыре Playwright-сценария: назначение и модерация; мобильная навигация без переполнения; приватность Direct и действительные PDF/XLSX; отрисовка рабочих разделов и импорт CSV. Ошибки выполнения JavaScript проверены в основном E2E-сценарии; отсутствуют. Генеративный LIVE без настроенного провайдера визуально не выдаётся за работающий.

final result: passed

Финальная production-проверка: четыре сценария проходят за 8,6 секунды суммарно; сервер оставлен на http://localhost:3001. Финальная совмещённая сверка повторно открыта после исправления веса заголовков; существенных замечаний нет.
