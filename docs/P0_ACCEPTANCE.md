# Покрытие P0 по ТЗ от 21.10.2026 и Business Vision

Связанные документы: [бизнес-домены](BUSINESS_DOMAIN.md), [фичи и код](features/README.md), [roadmap](ROADMAP.md), [FSD-архитектура](ARCHITECTURE.md).

Главная ось: раннее обнаружение публичной городской проблемы и подтверждённая передача ответственному подразделению. DEMO и LIVE изолированы на сервере; аналитика рассчитывается из сохранённых сущностей.

| Критерий раздела 8 | Реализация и проверка | Статус приёмки |
|---|---|---|
| 1. Не менее трёх источников, единая лента | Три настраиваемых канала, JSON/RSS адаптеры, ручной сбор, отдельный worker, CSV/XLSX импорт, нормализация и дедупликация | Механизм реализован; три реальных разрешённых подключения ещё нужны |
| 2. Подразделение, тональность, уверенность | Серверный structured Gemini с Zod-валидацией; отдельные уверенности и объяснения; RU/KZ; DEMO использует явно обозначенные правила | DEMO проверен; настоящий LIVE-вызов требует конфигурации |
| 3. Фильтрация и группировка | Период, источник, проблема, подразделение, район, тональность, приоритет, статус, поиск; URL и сохранённые фильтры; сортировка/группировка/пагинация | Проверено для DEMO |
| 4. Кластеры и приоритет | Совпадение темы, сферы и нормализованного адреса; разные/неизвестные адреса не сливаются; дедуп; объяснимые факторы тяжести, независимых авторов, роста, возраста и негатива | Проверено тестами и браузером; семантические дубли с перефразированием требуют следующей итерации |
| 5. Три дашборда, drill-down, экспорт | Общая картина, подразделения, проблемы; единые фильтры и переходы; настоящие CSV/XLSX/PDF с кириллицей | Проверено браузером, включая форматы файлов |
| 6. Тональность ≥80%, сфера ≥75% | Запускаемая smoke-оценка на 36 заранее размеченных RU/KZ примерах, ошибки и измеренная задержка | Smoke DEMO проходит целевые пороги; независимая тестовая выборка и LIVE не подтверждены |
| 7. Раздел 5: приватность и человек в контуре | Псевдонимизация автора; маскирование до AI; Direct только агрегаты в общем API/экспорте; серверные роли; подтверждение назначения; аудит; удаление записи администратором | Прототип проверен; промышленный правовой/PII/инфраструктурный аудит остаётся |
| 8. Direct или демонстрационный поток | Синтетический Direct через общий pipeline; просмотр обезличенного текста только admin/analyst с аудитом; viewer/department не получают текст | Проверено браузером и сервером; реальные Direct намеренно недоступны |
| 9. Демонстрация на реальных данных | Готовы ingest → Gemini → запись → кластер → дашборды → решение → экспорт | Не подтверждено без доступного провайдера и разрешённого реального набора |

Дополнительно: справочник тематик и ответственных редактируется администратором; его подсказки используются в последующих LIVE-запросах. Предусмотрены пять последовательных статусов и возврат решённой/закрытой проблемы в работу. Смена отдела сотрудником ограничена сервером. Доступ к исходному Direct и действия не скрываются лишь кнопками, а проверяются API.

Формула приоритета: тяжесть ≤40 + независимые авторы ≤20 + новые сообщения за 24 часа ≤20 + возраст нерешённости ≤15 + негатив ≤5, итог ≤100. ≥65 — высокий, ≥35 — средний, иначе низкий. Охват не придумывается: без измеренных метрик его вклад нулевой. Счётчик новых сообщений не выдаётся за рост процента при нулевой базе.

Разница с предыдущим периодом выводится только при наличии базы. При отсутствии времени назначения показан прочерк. Экономия человеко-часов и эффект раннего выявления не выдаются за измеренные результаты акимата.

За пределами P0: генеративный RAG, уведомления и автодайджесты, карта, интеграция с 109/eOtinish, промышленная инфраструктура, пользовательский OAuth и реальные Direct. Локальный поисковый ассистент включён как вспомогательный экран и подписан соответствующим образом.

## Проверки

- TypeScript: без ошибок.
- Тесты ядра и API-контрактов: 11 проходят.
- Браузер: 5 сценариев проходят — действия/экспорт/роли; mobile; Direct/форматы/справочник; экраны/CSV; форма доступа и сохранённые фильтры после FSD-переноса.
- Production webpack build: проходит. Turbopack заменён на webpack из-за ограничений процесса обработки CSS в данной среде.
- Зависимости закреплены точными версиями и lock-файлом. npm audit: 0 high/critical, 9 moderate в цепочке ExcelJS. Доступных совместимых исправлений audit не предлагает; использование здесь ограничено буферным XLSX, без пользовательских glob-паттернов. Перед промышленным выпуском цепочка требует обновления/замены.

Фактический локальный smoke-результат DEMO на 36 примерах: тональность 36/36 (100%), подразделение 35/36 (97,22%). Одна ошибка: казахская благодарность за подключение воды отнесена к «Другому». Это намеренно не исправлено под конкретный эталонный пример. Результат сохранён в `artifacts/quality-demo.json`. Задержка быстрых локальных правил округляется до миллисекунд и не является замером Gemini.


## Синхронизация архитектуры

Next.js adapters находятся в `app/api`, модели и чистые правила — в `src/entities`, пользовательские действия — в `src/features`, таблицы/панели/метрики — в `src/widgets`, экраны — в `src/pages`. Серверный конвейер перенесён в `src/server` без изменения приёмочных критериев. URL и контракт API сохранены.

Наличие кода не закрывает дополнительные разрывы ТЗ: UI добавления/полной настройки источника, CRUD подразделений и персональных пользователей, метрики охвата, полноценный графический PDF дашборда, использование исправлений для улучшения модели, репрезентативная проверка схожих RU/KZ обращений. Они явно отражены незавершёнными чекбоксами в roadmap. Исполнение этих работ не входит в данный структурный рефакторинг.

Проверки структуры: `npm run check:architecture` (FSD и серверная граница), `npm run check:docs` (12 карточек, пути реализации, домены/milestones и ссылки). История предыдущих функциональных проверок выше относится к поведению; после FSD-переноса выполняется тот же регрессионный набор.


Итог регрессии FSD: `npm run check` проходит (слои/public API/граница сервера, 12 карточек и ссылки, TypeScript); production webpack build проходит; 11 тестов ядра/контрактов проходят. Четыре исходных браузерных сценария прошли на финальной сборке; дополнительный сценарий формы доступа и сохранённых фильтров прошёл отдельно после исправления регистра его тестового селектора. Приложение оставлено на `http://localhost:3001`.
