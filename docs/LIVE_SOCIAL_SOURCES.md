## npm / React / Next.js

React — настройки и аналитика; fetch и токены — только сервер Next.js/worker.

- [vk-io](https://github.com/negezor/vk-io), npm `vk-io`: сообщественный Node.js SDK VK, не обходит требования токенов.
- [grammY](https://github.com/grammyjs/grammY), npm `grammy`: Bot API framework; не предоставляет историю произвольных каналов.
- [GramJS](https://github.com/gram-js/gramjs): MTProto; репозиторий помечен archived и указывает на `teleproto`. Не устанавливать устаревший клиент ради «доступа без авторизации».
- [snoowrap](https://github.com/not-an-aardvark/snoowrap): community Reddit wrapper; OAuth/одобрение Reddit остаются необходимыми.
- [Meta Node Business SDK](https://github.com/meta/facebook-nodejs-business-sdk): SDK Marketing APIs; не универсальный парсер публичных Instagram/Facebook обсуждений.
- [Cheerio](https://cheerio.js.org/docs/intro/): установлен точной версией для публичного статического HTML, без исполнения JS, login/cookies/CAPTCHA bypass.

API-адаптеры реализованы напрямую через серверный fetch: четыре небольших read-only API-вызова не требуют четырёх дополнительных SDK. Они ограничены известными API-хостами, таймаутом и размером ответа. Ошибки не включают токен/полный API-ответ.

## Подтверждённые реальные тесты

1. ПАВЛОДАРЭНЕРГО: HTTP 200, извлечены 3 самостоятельных обращения, 1 совпадение по ЖКХ-ключевым словам, даты присутствуют. Ответы компании не смешиваются с текстами жителей. Автор проходит существующую HMAC-псевдонимизацию только при последующем разрешённом ingest.
2. Открытый диалог, карточка 766288: HTTP 200, извлечено 1 полное обращение по жилищной теме, 1 совпадение. Это общереспубликанский ресурс; конкретное обращение нельзя выдавать за обращение из Павлодара. Дата имеет точность «день»: полночь Asia/Qyzylorda — техническое представление даты, не выдуманное время публикации. Список поддерживается с переходом к первым трём полным карточкам; обрезанные preview не выдаются за полный текст.
3. Настроенный Direct-бот: getMe HTTP 200, is_bot=true; getWebhookInfo HTTP 200, webhook отсутствует, pending_update_count=0. Это подтверждает токен/соединение, но не приём и AI-анализ нового обращения.
4. Анонимные VK/Instagram/Facebook вызовы не вернули контент — см. таблицу. Успешный сбор из двух соцсетей не заявляется.

Согласование регулярного сбора и передачи данных этих HTML-источников в AI не подтверждено. Кнопка «Проверить API» выполняет чтение/разбор и возвращает только счётчики, без Gemini и сохранения обращений. «Собрать» требует включённый источник и permission=true, обрабатывает обезличивание → Gemini → дедуп → SQLite → аналитику.

## Конкретные настройки панели

Номер секрета берётся из отображаемого source-N, а не из позиции строки. Источники можно добавлять кнопкой «Добавить источник»; новый источник выключен и не имеет разрешения по умолчанию.

### ПАВЛОДАРЭНЕРГО: уже протестирован HTML

- Название: `ПАВЛОДАРЭНЕРГО · обращения`.
- Метод: `HTML`.
- URL: `https://pavlodarenergo.kz/ru/blog-rukovoditelya/obrashhenie.html`.
- Город: `Павлодар`; область: `Павлодарская`; теги: `ЖКХ, отопление, электроснабжение`.
- Ключевые слова: `отопл,тепло,электро,жкх` (или пусто для первого теста).
- Интервал: `60`. Разрешение пока выключено; сохранить → «Проверить API»: ожидаются 3 обращения до фильтра, текущая страница меняется со временем.
- Для реального регулярного сбора вписать фактическое основание и подтвердить разрешение.

### Открытый диалог: уже протестирован HTML

- Метод: `HTML`; URL: `https://dialog.egov.kz/blogs/all-questions/766288` для воспроизведения теста.
- Для списка: `https://dialog.egov.kz/blogs/all-questions` (первые 3 полные карточки, без полноценной пагинации архива).
- Область: `Казахстан`; город оставить пустым. Теги: `жильё, обращения`.
- Ключевые слова: `жиль,тұрғын`; разрешение пока выключено; сохранить → «Проверить API».

### VK: комментарии к выбранному посту

- Кандидат для поиска городских обсуждений: `https://vk.com/tipavlo`. Доступ и право на обработку не подтверждены.
- В панели ссылка сообщества `https://vk.com/tipavlo` либо реальная ссылка нужного поста: `https://vk.com/wall-OWNER_ID_POST_ID`. Числа нужно взять из публикации, пример `123/456` не является готовым источником.
- Метод: `VK`; Meta ID пустой; город/область/теги задать для конкретного сообщества.
- Сервер: `CITYCOM_SOURCE_2_TOKEN=<допустимый VK token>` для source-2; `CITYCOM_VK_API_VERSION=<поддерживаемая версия вашего приложения>`.
- Сохранить → «Проверить API»; для сообщества читаются 3 последние публикации и до 30 комментариев каждой; для отдельного поста — до 30 последних комментариев. Затем локальный отбор по словам. Поиска по всей соцсети и вложенным веткам пока нет.

### Instagram / Facebook

- Подходящие кандидаты: `https://www.instagram.com/pavlodar_region/` и `https://www.facebook.com/pavlodarregion/`. Это адреса аккаунтов для поиска публикаций, не готовые URL comments API.
- Instagram: метод `Instagram`, публичная ссылка конкретного `/p/.../` либо `/reel/.../`, поле Meta ID — числовой Media ID **из официального API подключённого аккаунта**. Shortcode из ссылки не заменяет Media ID.
- Facebook: метод `Facebook`, ссылка конкретного поста, Meta ID — `PAGE_ID_POST_ID` из официального API.
- Для source-3: `CITYCOM_SOURCE_3_TOKEN=<соответствующий Meta token>`, общая `CITYCOM_GRAPH_API_VERSION=<поддерживаемая версия, например vNN.N из Dashboard приложения>`. Токены Instagram Login и Facebook Page не взаимозаменяемы.
- Реализована первая страница до 30 комментариев; не полный архив/все ответы. Произвольные аккаунты и поиск по всему Instagram/Facebook не поддерживаются.

### Telegram: собственный публичный opt-in канал

- Создать отдельный публичный канал и отдельного бота через BotFather; добавить бота администратором канала. Не включать webhook и сторонний polling.
- В панели: метод `Telegram`, URL `https://t.me/ВАШ_USERNAME`, город/область/теги; подтверждение индивидуального согласия авторов и документированное основание.
- Сервер source-2: `CITYCOM_SOURCE_2_TOKEN=<токен отдельного бота канала>`. Не `CITYCOM_TELEGRAM_BOT_TOKEN`: он занят Direct. Отдельный бот нужен для каждого публичного источника, чтобы offset одного канала не потерял обновления другого.
- Опубликовать **после добавления бота** собственный текст с точным префиксом: `Согласен на обработку и передачу обезличенного текста в Gemini. Обращение: Нет отопления на улице Тестовая 999.`
- При реальном использовании префикс не заменяет информирование и действительное согласие правообладателей. Пересланные материалы и чужие тексты без их согласия не подходят.
- «Проверить API» прочитает новые channel_post, но не вызовет Gemini/не изменит сохранённый cursor. «Собрать» обработает подходящие записи и сохранит cursor. Посты без префикса/другие каналы/приватные сообщения игнорируются.
- Кандидат `https://t.me/pavlodaronline` найден публично, но не подключается автоматически: это чужой новостной канал, не подтверждены установка нашего бота, индивидуальные согласия и право AI-обработки.

## Теги и фактическая география

В SQLite Source сохраняются `city`, `region`, `tags`, `keywords`. Первые три — метаданные ресурса. Они не подставляют адрес в обращение и не превращают национальную ленту в Павлодар. Ключевые слова — case-insensitive OR по подстрокам; пустые элементы после запятых игнорируются. Для ЖКХ и RU/KZ можно начать с `отопл,тепло,жылу,су жоқ,водоснабж,мусор,қоқыс,электро,жкх`. Семантический поиск по всей площадке не реализован.

## Обнаруженная конфигурация и P0

При проверке `.env.local`: Gemini key и Telegram token заполнены, но `AI_TRANSFER_APPROVED=false` и `CITYCOM_TELEGRAM_OWNER_APPROVED=false`. Пробный синтетический LIVE-анализ остановлен серверной проверкой **до вызова Gemini**. Флаги не переключались автоматически. Для разрешённого запуска владелец должен подтвердить соответствующие основания и установить true.

Три реально работающих публичных подключения, две соцсети с авторизованным доступом, качество LIVE на независимой выборке и реальный сквозной прогон пока не подтверждены. Direct остаётся отдельным источником по ТЗ. Полный P0 не объявляется закрытым по наличию адаптеров или успешному getMe.
