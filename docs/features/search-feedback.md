# F12 · Поисковая сводка по обращениям

- **Домен:** D10 — [связь доменов](../BUSINESS_DOMAIN.md).
- **Зачем:** Сотрудник спрашивает об обращениях по сфере, району, негативу или последней неделе и открывает основания.
- **Основание ТЗ:** 3.5.5, 6.1, 5.3, 5.4. Номера `8.n` обозначают n-й критерий раздела 8; в DOCX они перечислены без отдельных заголовков.
- **Business Vision:** Ускорить получение объяснимой сводки из собранной городской обратной связи.

## Поведение

Локальный разбор ограниченного набора признаков вопроса; сводка по текущей выборке; ссылки на карточки исходных записей.

## Инварианты

Direct исключён. Ответ явно обозначен как локальная поисковая сводка; при отсутствии данных нет выдуманных обращений.
