# F09 · Удаление записи по запросу

- **Домен:** D07 — [связь доменов](../BUSINESS_DOMAIN.md).
- **Зачем:** Администратор удаляет запись по запросу и видит результат операции.
- **Основание ТЗ:** 5.6, 3.6, 8.7. Номера `8.n` обозначают n-й критерий раздела 8; в DOCX они перечислены без отдельных заголовков.
- **Business Vision:** Обеспечить управляемость данных и соблюдение механизма удаления из ТЗ.

## Поведение

Подтверждение удаления; удаление обращения; удаление пустого кластера; запись факта действия в аудит.

## Инварианты

Удаление разрешено сервером только администратору. Журнал фиксирует факт операции без удалённого текста.
